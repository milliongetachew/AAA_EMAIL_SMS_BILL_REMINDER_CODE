      ***********************M D 0 5 8 C B******************************
      * THIS PROGRAM WILL READ IN A CCREJ FILE FROM EFT, READ HOUSEHOLD*
      * TABLE TO VERIFY BILLPLAN IS AC. IF BILLPLAN IS AC WILL CHANGE  *
      * BILLPLAN TO AM, OTHERWISE WILL WRITE RECORD TO EMS_WORK_CAU    *
      * IN LATER STEP RECORDS WILL BE UNLOADED AND AN OUT-OF-SYNC      *
      * REPORT WILL BE CREATED FROM THOSE RECORDS.                     *
      * IF BILLPLAN IS CHANGED TO AM RECORD WILL BE WRITTEN TO         *
      * EMS_WORK_CAU TABLE FOR EIP LETTER TO BE SENT TO MAILING ADDRESS*
      *IF BILLPLAN IS AC AND MEMBER LIVES OUT OF TERRITORY, RECORD     *
      *WILL BE WRITTEN TO EMS_WORK_CAU AND FILE WILL BE CREATED IN     *
      *LATER STEP.                                                     *
