                        MBR_N,
                        EMAIL_TEXT

       PROCEDURE DIVISION.

       0000-MAINLINE.

           PERFORM A0000-INITIALIZE.

           PERFORM B0000-PROCESS-MEMBER-RECS
             UNTIL MD572I1-EOF.

           PERFORM Z0000-WRAP-UP.

      ******************************************************************
      * INITIALIZE DATA, GET CURRENT DATE, OPEN FILES                  *
      ******************************************************************
       A0000-INITIALIZE.

           PERFORM A1000-GET-CURRENT-DATE.

           DISPLAY '**************************************************'.
           DISPLAY '*      PROGRAM MD572EM SUMMARY                   *'.
           DISPLAY '**************************************************'.

           PERFORM A2000-OPEN-FILES.

           PERFORM A3000-GET-PROCESS-DATE.

           PERFORM A3500-OPEN-CURSOR.

           PERFORM A4000-GET-ALL-CLUBS.

           INITIALIZE REPORT-REC-OUT.

           STRING 'DATE      '
                   WS-COMMA-FIRST
                  'CLUB'
                   WS-COMMA-LAST
                  'CLUB NAME'
                   WS-COMMA
                  'DECLINED CREDIT CARD CNT'
                   WS-COMMA
                  'MEMBER EMAIL COUNT'
                   WS-COMMA
                  '% OF EMAILS'
                   WS-COMMA
                  DELIMITED BY SIZE     INTO REPORT-REC-OUT
           END-STRING.

           WRITE REPORT-REC-OUT.

           PERFORM R0000-FETCH-MEMBER.
      /
      ******************************************************************
      * GET CURRENT DB2 DATE/TIME                                      *
      ******************************************************************
       A1000-GET-CURRENT-DATE.

           EXEC SQL
              SET :WS-CURRENT-DATE   = CHAR(CURRENT DATE, ISO),
                  :WS-CURRENT-TIME   = CHAR(CURRENT TIME, ISO)
           END-EXEC.

           IF  SQLCODE = +0
               DISPLAY
                  '**************************************************'
               DISPLAY '         PROGRAM ' WS-PGM-NAME ' STARTED    '
               DISPLAY '         RUN DATE & TIME: ' WS-CURRENT-DATE ,
                       ' ',                         WS-CURRENT-TIME
               DISPLAY
                  '**************************************************'
           ELSE
               DISPLAY '***********************************************'
               DISPLAY '**** SELECTION OF CURRENT DATE ERROR IN A1000- '
               DISPLAY '***********************************************'
               MOVE 'CURRENT DB2 DATE SELECT PROBLEM'
                                             TO MD900-ERROR-MSG-1
               MOVE SQLCODE                  TO MD900-SQLCODE
               MOVE SQLCA                    TO MD900-SQLCA
               MOVE 'A1000-GET-CURRENT-DATE' TO MD900-PARAGRAPH-NAME
               SET  MD900-DB2-FUNCTION-SET   TO TRUE
               SET  MD900-RC-DB2-SQL-ERROR   TO TRUE
               MOVE 'SET CURRENT DATE '      TO MD900-TABLE-CURSOR-NAME
               PERFORM Z9999-ERROR
           END-IF.
      /
      ******************************************************************
      * OPEN INPUT AND OUTPUT FILE.                                    *
      ******************************************************************
       A2000-OPEN-FILES.

           OPEN INPUT  CLUB-FILE-IN
                OUTPUT EMAIL-FILE-OUT
                       REPORT-FILE-OUT.
      /
      ******************************************************************
      * CALL MD930BR TO GET BATCH PROCESS DATE                         *
      ******************************************************************
       A3000-GET-PROCESS-DATE.

           INITIALIZE MD930-LINK-DATA
                      MD900-ERROR-DATA.

           CALL WS-MD930BR                   USING MD930-LINK-DATA
                                                   MD900-ERROR-DATA.

           IF  MD900-RC-OK
               MOVE MD930-ISO-DT             TO WS-PROCESS-DT
           ELSE
               MOVE 'A3000-GET-PROCESS-DATE' TO MD900-PARAGRAPH-NAME
               MOVE WS-MD930BR               TO MD900-PGM-NAME
               PERFORM Z9999-ERROR
           END-IF.
      /
      ******************************************************************
      * OPEN CUSOR.                                                    *
      ******************************************************************
       A3500-OPEN-CURSOR.

           EXEC SQL
             OPEN CURSOR-WORKTABLE
           END-EXEC.

           IF SQLCODE NOT = 0
               DISPLAY '***********************************************'
               DISPLAY '**** OPEN CURSOR ERROR IN A3500-               '
               DISPLAY '***********************************************'
               MOVE 'OPEN CURSOR PROBLEM            '
                                             TO MD900-ERROR-MSG-1
               MOVE SQLCODE                  TO MD900-SQLCODE
               MOVE SQLCA                    TO MD900-SQLCA
               MOVE 'A3500-OPEN-CURSOR     ' TO MD900-PARAGRAPH-NAME
               SET  MD900-DB2-FUNCTION-OPEN  TO TRUE
               SET  MD900-RC-DB2-SQL-ERROR   TO TRUE
               MOVE 'CURSOR-WORKTABLE '      TO MD900-TABLE-CURSOR-NAME
               PERFORM Z9999-ERROR
           END-IF.

      /
      ******************************************************************
      * READ INPUT FILE OF ALL CLUBS TO PROCESS                        *
      ******************************************************************
       A4000-GET-ALL-CLUBS.
           PERFORM UNTIL MD572I2-EOF
              READ CLUB-FILE-IN INTO CLUB-RECORD
                   AT END
                      SET MD572I2-EOF             TO TRUE
              END-READ
              IF  NOT MD572I2-EOF
                  ADD 1                 TO  IDX-TOT
                  SET IDX-C             TO  IDX-TOT
                  IF IDX-TOT > IDX-C-MAX
                     DISPLAY '-MD572EM- TABLE OVERFLOW '
                     DISPLAY '-MD572EM- CLUB TABLE    -'
                     DISPLAY '-MD572EM- EXPAND OCCURENCES '
                     DISPLAY '-MD572EM- ONLY 15 ALLOCATED '
                     MOVE 'TABLE OVERFLOW ON CLUB ENTRIES'
                                                TO MD900-ERROR-MSG-1
                     MOVE 'A4000-GET-ALL-CLUBS' TO MD900-PARAGRAPH-NAME
                     PERFORM Z9999-ERROR
                  ELSE
                     MOVE CLUB-IN       TO IDX-CLUB-CODE(IDX-C)
                     MOVE SPACES        TO IDX-CLUB-NAME(IDX-C)
                     MOVE ZEROES        TO IDX-CLUB-DECLINE(IDX-C)
                                           IDX-CLUB-EMAIL(IDX-C)
                                           IDX-CLUB-NO-EMAIL(IDX-C)
                                           IDX-CLUB-SKIP(IDX-C)
                                           IDX-CLUB-PAID(IDX-C)
                                           IDX-CLUB-CANCEL(IDX-C)
                     PERFORM A5000-GET-CLUB-NAME
                     MOVE MD03-CLUB-NAME TO IDX-CLUB-NAME(IDX-C)
                  END-IF
              END-IF
           END-PERFORM.

      ******************************************************************
      * CALL MD699BR TO GET ALL CLUB NAMES                             *
      ******************************************************************
       A5000-GET-CLUB-NAME.

           INITIALIZE MD699-INPUT-OUTPUT-RECORD
                      MD900-ERROR-DATA.

           MOVE CLUB-IN                      TO MD03-CLUB-CODE.
           MOVE WS-PROCESS-DT                TO MD03-PROCESSING-DATE.

           CALL  WS-MD699BR                  USING
                                             MD699-INPUT-OUTPUT-RECORD
                                             MD900-ERROR-DATA.

           IF  MD900-RC-OK
               CONTINUE
           ELSE
               MOVE 'A5000-GET-CLUB-NAME'    TO MD900-PARAGRAPH-NAME
               DISPLAY 'CLUB CODE: '         CLUB-IN
               MOVE WS-MD699BR               TO MD900-PGM-NAME
               PERFORM Z9999-ERROR
           END-IF.

      ******************************************************************
      * PROCESS MEMBER RECORDS FROM THE ULOAD FILES                    *
      ******************************************************************
       B0000-PROCESS-MEMBER-RECS.

           PERFORM B2000-CHECK-CARD-TYPE.

           IF CONTINUE-PROCESS
              PERFORM B2500-CHECK-BILL-PLAN
           END-IF.

           IF CONTINUE-PROCESS
              PERFORM B3000-GET-TOTAL-DUE
           END-IF.

           IF CONTINUE-PROCESS
             IF WS-AMOUNT-DUE = 0 THEN
      * THE MEMBER HAS PAID DURING THE 2 DAY WINDOW BETWEEN THE
      * CREDIT CARD REJECT AND NOW.  DELETE THE ROW FROM THE
      * WORK TABLE AND SKIP THIS RECORD
               PERFORM B7000-DELETE-CCREJ-ROW
               ADD 1 TO IDX-CLUB-PAID (IDX-C)
               SET BYPASS-RECORD TO TRUE
             ELSE
               IF FK-MBR-BILL-PLAN = 'AC' THEN
      * IF THE BILL PLAN IS STILL AC AND MEMBERSHIP STILL UNPAID
      * LEAVE ON WORK TABLE TO PICK UP THE NEXT DAY
                   ADD 1 TO IDX-CLUB-SKIP (IDX-C)
                   SET BYPASS-RECORD TO TRUE
               END-IF
             END-IF
           END-IF.

           IF CONTINUE-PROCESS
              PERFORM B4000-GET-EXPDT-YRSERV
           END-IF.

           IF CONTINUE-PROCESS
              PERFORM B5000-GET-16DIG-MBRSHP
           END-IF.

      * 10/11/17 - MQ START - MOVED FROM BEGINNING OF PARAGRAPH
      *                     - TO AFTER MEMBER VALIDATION
           IF CONTINUE-PROCESS
              PERFORM B1000-GET-CUSTOMER
              IF MC501-O-EMAIL > SPACES AND
                 (MC501-O-EMAIL-VALID-C = '1' OR '3')
                  CONTINUE
              ELSE
                 ADD 1 TO IDX-CLUB-NO-EMAIL (IDX-C)
                 SET BYPASS-RECORD         TO TRUE
                 PERFORM B7000-DELETE-CCREJ-ROW
              END-IF
           END-IF.
      * 10/11/17 - END

           IF CONTINUE-PROCESS
              PERFORM B6000-WRITE-EMAIL-REC
           END-IF.

           IF CONTINUE-PROCESS
              PERFORM B7000-DELETE-CCREJ-ROW
           END-IF.

           PERFORM R0000-FETCH-MEMBER.
      /
      ******************************************************************
      *  CALL MC501BCD TO GET CUSTOMER DATA INCLUDING EMAIL            *
      ******************************************************************
       B1000-GET-CUSTOMER.

           INITIALIZE MC501-INPUT-OUTPUT
                      MD900-ERROR-DATA.

           MOVE 1                          TO MC501-I-LOB-CODE.
           MOVE C206-CLUB-CODE             TO MC501-I-CLUB-CODE.
           MOVE C206-MEMBR-ID              TO MC501-I-PRODUCT-NUMBER.
           MOVE WS-PGM-NAME                TO MC501-I-CALLING-PROGRAM.
           MOVE '00'                       TO MC501-I-ROLE-CODE.
           MOVE 'Y'                        TO
                                           MC501-I-REQ-ALL-CUST-DATA.

           CALL WS-MC501BCD                  USING MC501-INPUT-OUTPUT.

           IF MC501-O-RETURN-CODE = ZEROES
              MOVE MC501-O-CUST-NUMBER        TO WS-CUST-ID
           ELSE
              SET BYPASS-RECORD               TO TRUE
              IF MC501-O-RETURN-MESSAGE = SPACES
                 MOVE 'PROBLEM WITH CALL TO MC501BCD'
                                              TO MD900-ERROR-MSG-1
              ELSE
                 MOVE MC501-O-RETURN-MESSAGE  TO MD900-ERROR-MSG-1
              END-IF
              DISPLAY '*** CUSTOMER NOT FOUND ****'
              DISPLAY 'CLUB CODE : '          C206-CLUB-CODE
              DISPLAY 'MEMBER ID : '          C206-MEMBR-ID
              MOVE C206-CLUB-CODE             TO MD900-KEY-DATA-LN(1)
              MOVE C206-MEMBR-ID              TO MD900-KEY-DATA-LN(2)
              MOVE MC501-O-RETURN-CODE        TO MD900-KEY-DATA-LN(3)
              MOVE 'B1000-GET-CUSTOMER'       TO MD900-PARAGRAPH-NAME
              MOVE WS-MC501BCD                TO MD900-PGM-NAME
              PERFORM Z9999-ERROR
           END-IF.

      ******************************************************************
      *  CHECK CARD TYPE                                               *
      ******************************************************************
       B2000-CHECK-CARD-TYPE.

           MOVE SPACES                     TO WS-CARD-TYPE-LONG.

           EVALUATE C206-CARD-TYPE
              WHEN 'VSN'
              WHEN 'VSA'
                MOVE 'VISA'                TO WS-CARD-TYPE-LONG
              WHEN 'MCN'
              WHEN 'MCA'
                MOVE 'MASTERCARD'          TO WS-CARD-TYPE-LONG
              WHEN 'AM'
                MOVE 'AMEX'                TO WS-CARD-TYPE-LONG
              WHEN 'DIS'
                MOVE 'DISCOVER'            TO WS-CARD-TYPE-LONG
              WHEN OTHER
                MOVE 'UNKNOWN'             TO WS-CARD-TYPE-LONG
           END-EVALUATE.

      ******************************************************************
      *  CHECK BILL PLAN                                               *
      ******************************************************************
       B2500-CHECK-BILL-PLAN.

           MOVE C206-CLUB-CODE TO FK-MHH-ACL-CLUB-C
           MOVE C206-MEMBR-ID TO FK-MHH-MBRSHP-N

           EXEC SQL
               SELECT FK_MBR_BILL_PLAN
               INTO  :FK-MBR-BILL-PLAN
               FROM   MBRSHP_NEXT_EVENT
               WHERE  FK_MHH_ACL_CLUB_C = :FK-MHH-ACL-CLUB-C
               AND    FK_MHH_MBRSHP_N   = :FK-MHH-MBRSHP-N
               FETCH FIRST 1 ROW ONLY
           END-EXEC.

           EVALUATE SQLCODE
           WHEN 0
               CONTINUE
           WHEN 100
      * IF NOT FOUND, ASSUME MEMBERSHIP WAS CANCELLED
      * DELETE EMS_WORK_CCREJ ROW
               PERFORM B7000-DELETE-CCREJ-ROW
               ADD 1 TO IDX-CLUB-CANCEL (IDX-C)
               SET BYPASS-RECORD TO TRUE
           WHEN OTHER
               DISPLAY '***********************************************'
               DISPLAY '**** SELECT ERROR IN R0000-                    '
               DISPLAY '***********************************************'
               MOVE 'SELECT PROBLEM                 '
                                             TO MD900-ERROR-MSG-1
               MOVE SQLCODE                  TO MD900-SQLCODE
               MOVE SQLCA                    TO MD900-SQLCA
               MOVE 'R0000-FETCH-MEMBER    ' TO MD900-PARAGRAPH-NAME
               SET  MD900-RC-DB2-SQL-ERROR   TO TRUE
               SET  MD900-DB2-FUNCTION-SELECT TO TRUE
               MOVE 'MBRSHP_NEXT_EVENT'      TO MD900-TABLE-CURSOR-NAME
               PERFORM Z9999-ERROR
           END-EVALUATE.

      ******************************************************************
      *  CALL MD610BR TO GET TOTAL DUE AMOUNT                          *
      ******************************************************************
       B3000-GET-TOTAL-DUE.

           INITIALIZE  MD610-LINK-DATA
                       MD960-MPD-DATA
                       MD900-ERROR-DATA
                       WS-AMOUNT-DUE.

           MOVE C206-CLUB-CODE               TO MD610-CLUB-CODE.
           MOVE C206-MEMBR-ID                TO MD610-MEMBERSHIP-NUMBER.
           MOVE WS-PROCESS-DT                TO MD610-PROC-DATE.
           SET MD610-BATCH                   TO TRUE.
           SET NO-ALLOC-PRIORITY             TO TRUE.
           MOVE WS-PGM-NAME                  TO MD610-CALLING-PROG.

           CALL WS-MD610BR                   USING MD610-LINK-DATA
                                                  MD960-MPD-DATA
                                                  MD900-ERROR-DATA.
           IF  MD900-RC-OK
               MOVE MD610-TOTAL-DUE          TO WS-AMOUNT-DUE
           ELSE
               MOVE C206-TXN-AMOUNT          TO WS-AMOUNT-DUE
           END-IF.
      /
      ******************************************************************
      *  GET HOUSEHOLD TABLE TO RETRIEVE YEARS OF SERVICE AND EXPDT    *
      ******************************************************************
       B4000-GET-EXPDT-YRSERV.

           PERFORM B4100-GET-EXPIRATION.

           PERFORM B4200-GET-JOIN-YEAR.

           COMPUTE WS-YEAR-SERV-9  = WS-EXP-YEAR - WS-AAA-JOIN-YR
