       00000-MAIN-LINE.

      *    DISPLAY PARAGRAPH-NAME.

      /===============================================================*
      *  INITIALIZE AND OPEN FILES
      *===============================================================*
       A0000-INITIALIZE.

           MOVE 'A0000-INITIALIZE'             TO PARAGRAPH-NAME.
      *    DISPLAY PARAGRAPH-NAME.

           PERFORM A1000-OPEN-FILES.

           PERFORM A3000-GET-PROCESS-DATE.

           PERFORM A4000-GET-JOB-NAME.
      ***MEM-18-01C begin******************
           PERFORM A5000-WRITE-HEADER.
      ***MEM-18-01C end  ******************

           PERFORM R0000-READ-EIP-FILE-IN.

      *===============================================================*
       A1000-OPEN-FILES.

           OPEN INPUT  EIP-FILE-IN
                OUTPUT EMAIL-FILE-OUT.

           IF  (MD134IP-STATUS NOT = 00 OR
                MD134OP-STATUS NOT = 00)
               MOVE 'A1000-OPEN-FILES'        TO MD900-PARAGRAPH-NAME
               MOVE WS-PGM-NAME               TO MD900-PGM-NAME
               MOVE 'FILES OPEN ERROR'        TO MD900-ERROR-MSG-1
               MOVE MD134IP-STATUS            TO MD900-KEY-DATA-LN(1)
               MOVE MD134OP-STATUS            TO MD900-KEY-DATA-LN(2)
               PERFORM Z9999-ERROR
           END-IF.

      ******************************************************************
      * CALL MD930BR TO GET BATCH PROCESS DATE                         *
      ******************************************************************
       A3000-GET-PROCESS-DATE.

           INITIALIZE MD930-LINK-DATA
                      MD900-ERROR-DATA.

           CALL WS-MD930BR                   USING MD930-LINK-DATA
                                                   MD900-ERROR-DATA.

           IF  MD900-RC-OK
      * INC943560 begin
               MOVE MD930-ISO-DT             TO WK-BEGIN-DATE
                                                WK-END-DATE
      * INC943560 end
           ELSE
               MOVE 'A3000-GET-PROCESS-DATE' TO MD900-PARAGRAPH-NAME
               MOVE WS-MD930BR               TO MD900-PGM-NAME
               MOVE 'CALL TO MD930BR FAILED' TO MD900-ERROR-MSG-1
               PERFORM Z9999-ERROR
           END-IF.
      /

      ******************************************************************
       A4000-GET-JOB-NAME.

                                  MD900-ERROR-DATA.
           IF MD900-RC-OK
              CONTINUE
           ELSE
               MOVE 'A4000-GET-JOB-NAME'     TO MD900-PARAGRAPH-NAME
               MOVE WS-MD920BR               TO MD900-PGM-NAME
               MOVE 'CALL TO MD920BR FAILED' TO MD900-ERROR-MSG-1
               PERFORM Z9999-ERROR
           END-IF.

       B0000-PROCESS-EIP-RECS.

           MOVE 'B0000-PROCESS-EIP-RECS' TO PARAGRAPH-NAME.
      *    DISPLAY PARAGRAPH-NAME.

           PERFORM B0100-WILL-EMAIL-BE-PRODUCED.

           IF MD607-EMAIL-CORR-TYPE-C > SPACES AND
              MD607-BILL-CORR-TYPE-ECORR AND
              MD607-PROCESS-NEW AND
              MDEIP-ADDR-EMAIL > SPACES
              SET SEND-EMAIL                   TO TRUE
      * INC943560 begin
              IF MDEIP-LETTER-C = '139'

              IF SEND-EMAIL

              END-IF
      * INC943560 end
           END-IF.

      * DETERMINE IF EMAIL NEEDS TO BE PRODUCED                       *

       B0100-WILL-EMAIL-BE-PRODUCED.

           INITIALIZE                             MD607-INPUT-OUTPUT.
           MOVE MDEIP-CLUB-C                   TO MD607-CLUB-C.

           MOVE MDEIP-LETTER-C                 TO MD607-LETTER-C.
           MOVE MD930-DB2-PROC-DT              TO MD607-EFF-D.

                                                  MD900-ERROR-DATA.

               CONTINUE
           ELSE

               DISPLAY '***MD125EM - B0100-WILL-EMAIL-BE-PRODUCED'
               DISPLAY '***CLUB/LETTER USED ' MDEIP-CLUB-C '/'
                              MDEIP-LETTER-C
               DISPLAY '********************************************'
               MOVE MDEIP-CLUB-C              TO MD900-KEY-DATA-LN(1)
               MOVE MDEIP-LETTER-C            TO MD900-KEY-DATA-LN(2)
               MOVE 'B0100-WILL-EMAIL-BE-PRODUCED'
                                              TO MD900-PARAGRAPH-NAME
               MOVE WS-MD607BR                TO MD900-PGM-NAME
               PERFORM Z9999-ERROR
           END-IF.

      * INC943560 begin
       B0200-DO-NOT-SEND-EMAIL.

           MOVE MDEIP-CLUB-C        TO WS-CLUB-C
           MOVE MDEIP-MBRSHP-N      TO WS-MBRSHP-N

           EXEC SQL
                SELECT COUNT(*)
                  INTO :WS-COUNT
                  FROM MBRSHP_MONTHLY_CHARGE_DTL
                 WHERE FK_MHH_ACL_CLUB_C = :WS-CLUB-C
                   AND FK_MHH_MBRSHP_N   = :WS-MBRSHP-N
                   AND (CHARGE_ADJ_TYPE = 'ADD' OR
                        CHARGE_ADJ_TYPE = 'CANCEL')
                   AND CHG_EFF_S BETWEEN :WK-BEGIN-TS
                                     AND :WK-END-TS
         -------- creatd on the web ------------------------------
                   AND DA_EMP_SECT_N = '36  '
                   AND DA_EMP_USER_ID_N = '009999'
           END-EXEC.

           EVALUATE SQLCODE
           WHEN MD903-SQL-OK
                IF WS-COUNT > 0
                   SET NOT-SEND-EMAIL              TO TRUE
                END-IF
           WHEN OTHER
               DISPLAY '********************************************'
               DISPLAY '*** B0200-DO-NOT-SEND-EMAIL-FOR-139      '
               DISPLAY '*** CLUB   = ' MDEIP-CLUB-C
               DISPLAY '*** MBRSHP = ' MDEIP-MBRSHP-N
               DISPLAY '*** SQL CD = ' SQLCODE
               DISPLAY '********************************************'
               MOVE MDEIP-CLUB-C              TO MD900-KEY-DATA-LN(1)
               MOVE MDEIP-MBRSHP-N            TO MD900-KEY-DATA-LN(2)
               MOVE SQLCODE                   TO MD900-KEY-DATA-LN(3)
               MOVE 'B0200-DO-NOT-SEND-EMAIL-FOR-139'
                                              TO MD900-PARAGRAPH-NAME
               MOVE WS-PGM-NAME               TO MD900-PGM-NAME
               PERFORM Z9999-ERROR
           END-EVALUATE.
      * INC943560 end

           MOVE MD930-PROC-DY            TO MD134-O-EXT-DY.
           MOVE MD930-PROC-YR            TO MD134-O-EXT-YR.

           MOVE MDEIP-MBRSHP-N           TO MD134-O-MBRSHP-NBR.
           MOVE MDEIP-REN-TERM-EXP-D     TO MD134-O-EXP-DATE.
           MOVE MDEIP-BILL-PLAN          TO MD134-O-BILL-PLAN.

           PERFORM B3000-CALL-MD999CK.

           MOVE MD999CK-CHECK-DIGIT      TO MD134-O-MBRSHP-NBR-16.
           MOVE MDEIP-TOTAL-DUES-MP      TO MD134-O-MONTHLY-DUE.
           MOVE MDEIP-TOTAL-PAST-DUES-MP TO MD134-O-PAST-DUE.

           IF MD134-O-EMAIL-TYPE = 'MPNOAUTHPMT'
              IF MDEIP-TOTAL-PAST-DUES-MP > 0
                 MOVE 'MPNOAUTHNOPMT'    TO MD134-O-EMAIL-TYPE
              ELSE
                 MOVE 'MPNOAUTH'         TO MD134-O-EMAIL-TYPE
              END-IF
           END-IF.

           MOVE MDEIP-PAY-DAY-OF-THE-MONTH
                                         TO MD134-O-PAY-DAY-OF-MONTH.
           MOVE MDEIP-AUTOPAY-ACCT-LAST-4
                                         TO MD134-O-CREDIT-CARD-LAST4.
           MOVE MDEIP-CUST-ID            TO MD134-O-CUSTOMER-NBR.
           MOVE MDEIP-MRD-NAME-SUFFIX (1)TO MD134-O-NAME-SUFFIX.
           MOVE MDEIP-MRD-NAME-FIRST (1) TO MD134-O-FIRST-NAME.
           MOVE MDEIP-MRD-NAME-LAST (1)  TO MD134-O-LAST-NAME.
           MOVE MDEIP-ADDR-EMAIL         TO MD134-O-EMAIL.
      ***MEM-18-01C BEGIN**************
           MOVE SPACES TO MD134-O-RENEWAL-DATE
           EVALUATE MD134-O-EXP-MO
             WHEN '01'
               STRING 'January ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '02'
               STRING 'February ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '03'
               STRING 'March ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '04'
               STRING 'April ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '05'
               STRING 'May ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '06'
               STRING 'June ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '07'
               STRING 'July ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '08'
               STRING 'August ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '09'
               STRING 'September ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '10'
               STRING 'October ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '11'
               STRING 'November ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
             WHEN '12'
               STRING 'December ' MD134-O-EXP-DY
                  DELIMITED BY SIZE   INTO MD134-O-RENEWAL-DATE
           END-EVALUATE.

           MOVE MDEIP-MRD-AAA-JOIN-YEAR(1) TO WS-JOIN-YEAR
           MOVE MD134-O-EXP-YR  TO WS-EXP-YEAR
           SUBTRACT WS-JOIN-YEAR FROM WS-EXP-YEAR
              GIVING WS-YEARS-MEMBER

           END-IF
           MOVE WS-YEARS-MEMBER          TO MD134-O-YEARS-MBR

              MOVE '  ' TO MD134-O-YEARS-MBR(1:2)

              IF WS-YEARS-MEMBER < 100
                 MOVE ' ' TO MD134-O-YEARS-MBR(1:1)
              END-IF
           END-IF

           MOVE MDEIP-ADDR-ZIP           TO MD134-O-ZIPCODE.

           ADD 1 TO MDEIP-SPINOFF-MAX-AGE
             GIVING WS-SPINOFF-AGE
           MOVE WS-SPINOFF-AGE           TO MD134-O-SPINOFF-AGE.
      ***MEM-18-01C END  **************

           INSPECT MD134-RECORD REPLACING ALL ';' BY SPACES.
           MOVE ';'                      TO MD134-O-SEPARATOR-1
                                            MD134-O-SEPARATOR-2
                                            MD134-O-SEPARATOR-3
                                            MD134-O-SEPARATOR-4
                                            MD134-O-SEPARATOR-5
                                            MD134-O-SEPARATOR-6
                                            MD134-O-SEPARATOR-7
                                            MD134-O-SEPARATOR-8
                                            MD134-O-SEPARATOR-9
                                            MD134-O-SEPARATOR-10
                                            MD134-O-SEPARATOR-11
                                            MD134-O-SEPARATOR-12
                                            MD134-O-SEPARATOR-13
                                            MD134-O-SEPARATOR-14
                                            MD134-O-SEPARATOR-15
                                            MD134-O-SEPARATOR-16
                                            MD134-O-SEPARATOR-17
                                            MD134-O-SEPARATOR-18
                                            MD134-O-SEPARATOR-19
                                            MD134-O-SEPARATOR-20.

           WRITE EMAIL-REC-OUT               FROM MD134-RECORD.
           ADD 1                             TO WS-EMAIL-COUNT.

      * MEM-481279 START
           IF MDEIP-LETTER-C = '139'
              MOVE SPACES              TO WS-HOLD-CORR-TYPE
              MOVE '639'               TO WS-HOLD-CORR-TYPE
              PERFORM B4000-UPDATE-CORR-HIST
           END-IF.
      * MEM-481279 END

      /
      ******************************************************************
      *  CALL MD999CK TO GET 16 DIGIT MEMBERSHIP NUMBER                *

       B3000-CALL-MD999CK.

           INITIALIZE MD999-LINK-DATA.

           MOVE MDEIP-CLUB-C                 TO MD999CK-CLUB-CODE.
           MOVE MDEIP-PRINT-MBRSHP-N         TO MD999CK-MEMBER.
           MOVE '0'                          TO MD999CK-ROLE-CODE.

      *** NOTE: THERE IS NO RETURN CODE OR ERROR INFO COMING BACK FROM
      *** MD999CK. IT EITHER ABENDS OR RETURNS THE DATA.

           CALL WS-MD999CK                   USING MD999-LINK-DATA.

      * MEM-481279 START
      ******************************************************************
      *  CALL MD300MA TO UPDATE CORRESPONDENCE HISTORY TABLE           *
      ******************************************************************
       B4000-UPDATE-CORR-HIST.
      *************************************************************

           INITIALIZE                     MD300-RETURN-INFORMATION
                                          MD300-PASSED-INFORMATION.

           SET  MD300-UPDATE-REQUESTED TO TRUE.

           SET  MD300-TODAYS-DATE      TO TRUE

           MOVE 'ADD'                  TO MD300-ACTION-REQUESTED.

           MOVE MDEIP-CLUB-C           TO MD300-CLUB-CODE.

           MOVE MDEIP-MBRSHP-N         TO MD300-MEMBER-NUMBER
                                          MD300-FK-MHH-MBRSHP-N(1).

           MOVE MD930-ISO-DT           TO MD300-SEND-DATE
                                          MD300-SEND-D(1)
                                          MD300-PROCESSING-D(1)

           MOVE 'Y'                    TO MD300-CHG-PROCESSING-D
           MOVE 1                      TO MD300-INDICATOR

           MOVE MDEIP-CLUB-C           TO MD300-CMC-CLUB-CODE
                                          MD300-FK-CMC-ACL-CLUB-C(1)
                                          MD300-FK-MHH-ACL-CLUB-C(1).

                                          MD300-FK-MBR-MRO-ROLE-C(1).

           MOVE MD930-DB2-PROC-DT      TO MD300-MBR-EFF-D
                                          MD300-FK-MBR-EFF-D(1).
           MOVE WS-HOLD-CORR-TYPE      TO MD300-CORR-TYPE
                                          MD300-FK-CMC-CORR-TYPE-C(1).


           CALL WS-MD300MA          USING MD300-RECORD.

           EVALUATE TRUE
           WHEN MD300-NO-ERRORS
                CONTINUE
           WHEN MD300-MEMBER-REC-NOT-FND
                DISPLAY '**MBRSHIP IS CANCELLED       **'
                        '**CORRESPONDENCE NOT WRITTEN **'
                         WS-CLUB-C '/' WS-MBRSHP-N
           WHEN MD300-ERROR-SQLCODE = 100
                DISPLAY '**MBRSHIP MISSING            **'
                        '**CORRESPONDENCE NOT WRITTEN **'
                         WS-CLUB-C '/' WS-MBRSHP-N
           WHEN OTHER
               MOVE WS-MD300MA                 TO MD900-PGM-NAME
               MOVE '1970-UPDATE-CORR-HIST'    TO MD900-PARAGRAPH-NAME
               MOVE WS-CLUB-C                  TO MD900-KEY-DATA-LN(1)
               MOVE WS-MBRSHP-N                TO MD900-KEY-DATA-LN(2)
               MOVE WS-HOLD-CORR-TYPE          TO MD900-KEY-DATA-LN(3)
               IF  MD300-ERROR-PROBLEM-NAME > SPACES
                   MOVE MD300-ERROR-PROBLEM-NAME
                                               TO MD900-ERROR-MSG-1
